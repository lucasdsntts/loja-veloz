# Projeto Loja Veloz 🚀

Sistema de e-commerce baseado em microsserviços, desenvolvido para demonstrar arquitetura moderna, conteinerização, orquestração e observabilidade.

## 🛠️ Tecnologias Utilizadas
* **Node.js & Alpine Linux** (Microsserviços e Containers)
* **Docker & Docker Compose** (Empacotamento e Orquestração Local)
* **Kubernetes** (Orquestração em Nuvem / Alta Disponibilidade)
* **GitHub Actions** (Pipeline de CI/CD automatizado)
* **OpenTelemetry & Jaeger** (Rastreamento Distribuído)
